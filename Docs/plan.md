## 2. 依赖关系与并行

```text
P0 ──► P1 ──► P2 ──► P3 ──► P4 ──┐
                 │               ├──► P6 ──► P7 ──► P8 发布
                 └──► P5（模型训练，外部周期）──┘
```

- P0 的分辨率结论 → P3 解码规格、P4 吞吐预算、P5 ModelSpec 输入
- P5 与 P1–P4 完全并行；P5 的 ModelSpec 草案尽早冻结输入格式（分辨率/采样率），避免 P6 返工
- P7 的 LLM 本地引擎选型（MediaPipe LLM / llama.cpp）可在 P3 期间用样机预研
